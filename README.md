# x-ui-ch

3x-ui 中文管理面板，基于 MHSanaei/3x-ui。

## 一键安装

```bash
bash <(curl -Ls https://raw.githubusercontent.com/LJR338/x-ui-ch/main/install.sh)
```

## 做了什么

1. 安装 MHSanaei 官方 3x-ui
2. 用中文版管理脚本 `x-ui_CN.sh` 替换默认菜单
3. 包含 BBR 加速管理（基于 chiakge 的 tcp.sh）

## 使用

安装完成后输入：

```bash
x-ui
```

即可进入中文管理菜单。
